# آپ‌مارکت — UpMarket

**کارمند فروش و مارکتینگ هوش مصنوعی برای فروشگاه‌های آنلاین.**

صاحب فروشگاه محصولش را وارد می‌کند؛ سیستم تحلیل می‌کند، پوستر و ویدیو و کپشن
می‌سازد، با مشتری چت می‌کند، سفارش می‌گیرد و منتشر می‌کند.

---

## شروع سریع

```
Code/UpMarket/start.bat
```

بک‌اند، داشبورد و سایت عمومی را با هم بالا می‌آورد:

| سرویس | آدرس |
|---|---|
| داشبورد (پنل فروشگاه‌دار) | http://localhost:5173 |
| سایت عمومی | http://localhost:3001 |
| مستندات API | http://localhost:8000/api/docs/ |
| پنل ادمین | http://localhost:8000/admin/ — `admin` / `admin1234` |

**بدون GPU هم کار می‌کند:** در `Code/UpMarket/backend/.env` مقدار `AI_API_BASE_URL`
را بگذار تا متن و بینایی از API بیایند. آن‌وقت Ollama و ComfyUI اصلاً اجرا نمی‌شوند.

## ساختار کد

```
Code/UpMarket/
├── backend/     Django + DRF + Celery — هسته و APIها
├── frontend/    React + Vite — داشبورد فروشگاه‌دار (پشت لاگین)
├── website/     Next.js — سایت عمومی (برای سئو)
├── redis/       ردیس پرتابل، بدون نیاز به نصب
├── docs/        مستندات معماری
└── start.bat    لانچر یک‌کلیکی
```

هر پوشه README خودش را دارد — برای جزئیات راه‌اندازی همان را بخوان.

## ساختار هر پوشه

```
NN-دسته/
├── poster.png        تصویر تولیدشده با FLUX
├── caption.txt       کپشن تولیدشده
└── segment-NN.mp4    قطعات ویدیو (فقط دکوراسیون)
```

## قواعد

- **نام فایل‌ها لاتین است** تا مسیرشان در وب و Flask بدون encoding کار کند.
- هر نمونه‌ی جدید باید در `../0-منبع/data.json` زیر کلید `portfolio`
  ثبت شود، و تصویرش در `../2-ارائه/static/portfolio/` کپی شود.
- کپشن‌ها **از همین فایل‌های متنی** خوانده می‌شوند — در قالب اسلاید کپی
  نشده‌اند، پس ویرایش فایل کافی است.

## اضافه کردن نمونه‌ی جدید

۱. پوشه‌ی `NN-دسته/` بساز و `poster.png` و `caption.txt` را بگذار
۲. تصویر را در `../2-ارائه/static/portfolio/<id>.png` کپی کن
۳. در `data.json` زیر `portfolio` یک ورودی اضافه کن:

```json
{
  "id": "shoes",
  "category": "کفش",
  "product": "کتانی روزمره",
  "image": "portfolio/shoes.png",
  "videos": [],
  "caption_file": "04-کفش/caption.txt"
}
```

۴. اگر می‌خواهی در اسلاید دیده شود، `2-ارائه/templates/slides/work1.html` را
   به‌روز کن (فعلاً دو نمونه‌ی اول را نشان می‌دهد).

## هدف بعدی

طبق استراتژی ورود به بازار (اسلاید ۱۵)، برای فاز صفر به **۲۰ نمونه‌ی واقعی**
از دسته‌های مختلف نیاز است — پوشاک، اکسسوری، دکوراسیون، غذا، خدمات و دیجیتال.
الان ۳ تا داریم.

درست نشده‌اند.

## اجرا

**دابل‌کلیک روی [`اجرا.bat`](اجرا.bat)** — تطبیق داده با کد را چک می‌کند،
مستندات را بازتولید می‌کند، گزارش مالی می‌دهد و ارائه را بالا می‌آورد.

یا دستی:

```bash
pip install flask
cd 2-ارائه && python app.py       # http://127.0.0.1:5100
```

## قانون یکپارچگی

**هیچ عددی دو جا نوشته نمی‌شود** — و این تا داخل خودِ محصول ادامه دارد:

```
0-منبع/data.json
      ↓
0-منبع/model.py ──┬── 2-ارائه/            هر دو ارائه
                  ├── 1-مستند-داخلی/      با build_docs + stitch
                  └── seed_plans ──→ دیتابیس ──→ /api/v1/plans/ ──→ سایت عمومی
```

قیمت پکیج حرفه‌ای را در `data.json` عوض کن؛ هر دو ارائه، همه‌ی مستندات،
پلن‌های داخل محصول و صفحه‌ی قیمت سایت عمومی خودکار به‌روز می‌شوند.

## نگهداری

```bash
cd 0-منبع
python check.py         # آیا داده هنوز با کد می‌خواند؟
python model.py         # گزارش مالی در ترمینال
python build_docs.py    # بازتولید چهار مستند
python stitch.py        # بازسازی مستند کامل
```

بعد از تغییر قیمت‌ها، در بک‌اند هم اجرا کن:

```bash
cd ../../Code/UpMarket/backend
python manage.py seed_plans
```

## خلاصه‌ی مدل

|---|---|
| سرمایه سخت‌افزار | ۶۰۰ میلیون تومان (۲× RTX 3060 12GB) |

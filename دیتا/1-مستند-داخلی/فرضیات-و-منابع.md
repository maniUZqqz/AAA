# فرضیات و منابع

هر عددی که در ارائه می‌بینی یکی از این چهار برچسب را دارد.
قبل از ارائه به سرمایه‌گذار، ردیف‌های «نیازمند تأیید» را با قیمت روز به‌روز کن.

| برچسب | معنی |
| --- | --- |
| `owner` | داده‌ی مالک پروژه (یادداشت خام اصلی) |
| `code` | استخراج‌شده از کد واقعی پروژه در Code/UpMarket |
| `derived` | محاسبه‌شده از داده‌های بالا |
| `estimate` | تخمین — نیازمند تأیید با قیمت روز |

## ردیف‌هایی که باید تأیید شوند

| مورد | مقدار فعلی | چرا مهم است |
| --- | --- | --- |
| نرخ دلار | ۲۳۵٬۰۰۰ تومان | هزینه‌ی سرور ابری و API خارجی را تعیین می‌کند؛ روی گزینه‌ی سرور شخصی اثری ندارد |
| اجاره GPU ابری | $۰.۵ در ساعت | پایه‌ی ستون «سرور ابری» در مقایسه‌ی زیرساخت |
| قیمت API ویدیو | $۰.۰۵ هر ثانیه | پایه‌ی ستون «API خارجی» |
| قیمت سیستم‌ها | ۶۰۰٬۰۰۰٬۰۰۰ تومان | روی استهلاک، هزینه ثابت و بازگشت سرمایه اثر مستقیم دارد |
| TAM بازار | ۱۱٬۰۰۰ میلیارد تومان | داده‌ی قدیمی است — با گزارش روز بازار تبلیغات دیجیتال جایگزین شود |

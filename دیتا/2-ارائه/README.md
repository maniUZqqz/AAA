# ارائه

دو ارائه از یک منبع داده. هیچ عددی داخل قالب‌ها نوشته نشده — همه از
`../0-منبع/data.json` خوانده و با `model.py` محاسبه می‌شوند.

```bash
pip install flask
python app.py
```

→ <http://127.0.0.1:5100> (یا `../اجرا.bat`)

---

و در هر دو ارائه استفاده می‌شوند.

## معماری

```
app.py                  یک روت داینامیک /deck/<deck>/<num>
  ↳ CUSTOMER / INVESTOR  فهرست اسلایدهای هر ارائه
  ↳ context_processor    m (مدل)، d (داده)، captions، توابع قالب‌بندی

templates/home.html      صفحه‌ی انتخاب مخاطب
templates/base.html      چیدمان مشترک، ناوبری، نوار پیشرفت
templates/slides/*.html  فقط محتوا — بدون CSS، بدون عدد ثابت
                         c_* مخصوص مشتری · بقیه سرمایه‌گذار یا مشترک

static/css/deck.css      تنها فایل استایل
static/js/deck.js        کیبورد، سوایپ، پخش خودکار ویدیو
static/fonts/            وزیرمتن، لوکال — بدون CDN
static/portfolio/        نمونه‌کارها
```

## اضافه کردن اسلاید

۱. فایلی در `templates/slides/` بساز که `base.html` را extend کند
۲. یک سطر به `CUSTOMER` یا `INVESTOR` در `app.py` اضافه کن

شماره‌گذاری، ناوبری، نوار پیشرفت و فهرست پرش خودکارند.

---

## نکات

- **فونت وزیرمتن لوکال باندل شده.** هیچ وابستگی به اینترنت یا CDN نیست —
  ارائه در جلسه‌ی بدون اینترنت هم کامل کار می‌کند.
- `app.py` هر درخواست `data.json` را تازه می‌خواند، پس ویرایش داده بدون
  ری‌استارت سرور دیده می‌شود.
- عدد جدید لازم داری؟ اول به `model.py` اضافه‌اش کن، بعد در قالب صدا بزن —
  هرگز مستقیم در قالب حساب نکن.
